# Architecture

The maintained architecture description is [../ARCHITECTURE.md](../ARCHITECTURE.md).

This v2 project uses PB0/COMP1 for RX, PE9/TIM1 for optical TX, and
PB10/PB11/USART3 for the Raspberry Pi. Historical PB2, ADC sampled-RX, TIM6
software-RX, and TIM3 TX descriptions do not apply to this hardware.
