# Mechanical Design

Use this folder for drone-mounted VLC hardware design.

Suggested structure:

```text
mechanical_design/
  inventor/       # Native Autodesk Inventor files
  exports/        # STEP/STL/PDF exports intended for sharing
  mounts/         # LED, photodiode, lens, and PCB supports
  notes/          # Assembly notes, tolerances, alignment notes
```

Avoid committing large generated exports unless they are needed for review or fabrication.
