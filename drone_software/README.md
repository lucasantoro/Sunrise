# Drone Software

Use this folder for software that integrates the VLC communication system with drones.

Possible contents:

- companion-computer scripts;
- ROS/MAVROS nodes;
- PX4/ArduPilot integration notes;
- telemetry bridge code;
- communication health monitoring;
- flight-test scripts.

Suggested structure:

```text

  companion/
  ros/
  px4/
  ardupilot/
  tests/
```
